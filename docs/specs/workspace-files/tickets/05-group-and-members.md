# 05 A group's panel switches to each member's workspace

**Status.** done

**What to build.**

- In a group chat, the panel shows the group's workspace first. A switch at its top names the group and each active member.
- Choosing a member lists that member's own workspace through the same routes, by the member's chat.
- Delete and live changes work there the same way.
- The frontend already knows a group's members. The panel uses them.

**Checks.**

- The frontend typecheck passes.
- In the real app, Files in Team shows Team's workspace, and switching to Assistant shows Assistant's.
