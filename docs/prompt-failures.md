# Prompt failures

Every model-facing wording that exists because a model got it wrong, one line
each: the constant (or symbol) that carries the wording, the date, the model, and
what it did. The wording itself lives in code, in `backend/harness/prompts.py` unless it is a
tool's own description; this is the record CLAUDE.md's
"Prompt text is code" invariant asks for. Add a line when a wording changes for
a failure; never delete one, the failure is still the reason.

| Symbol | Observed | Failure |
|--------|----------|---------|
| `REFERENCES_NOTE` (`prompts.py`) | before 2026-09-19, 7.5B model | Handed four TypeScript declarations for tools already in its list, it wrote a program to call them three runs out of three; nothing had said the list changed. Anthropic's API expands `tool_reference` blocks itself; an OpenAI-compatible endpoint cannot, so this sentence does the telling. |
| `DenoRunner._unanswered` error text (`sandbox/deno.py`) | before 2026-09-19, 4B model | A script called `main();` without `await`, returned at once, and the reply to the in-flight call met a closed pipe; "handler is closed" told the model nothing and it gave up. Told only "must be awaited", it deleted the `main();` line and shipped four scripts that declared `main` and never called it, so the text names the fix: `return await main();`. |
| `PRUNED` (`prompts.py`) | before 2026-09-19 | A model told only "[cleared]" asked the person what the tool had said, so the placeholder says to call the tool again. |
| `COMPACTION_INSTRUCTION` (`prompts.py`) | before 2026-09-19 | "Do NOT mention": a model that sees a summarization request in its history otherwise opens its next reply with "as summarized above". | `NO_PROGRESS_WARNING`, `NO_PROGRESS_REFUSAL` (`prompts.py`) | 2026-09-13, 12B model | Ran the identical program twice, received the identical result twice, and with nothing telling it the second was the first again, answered with an invented address instead of the next tool. |
| `GET_FUNCTION_DETAILS_DESCRIPTION` (`tools/native/code_mode/prompts.py`) | before 2026-09-19 | "callable directly" is the sentence that turns reading a schema into selecting the tool; without it the model reads the types and then writes a program for a single call, a script per step: every cost of code mode and none of its saving. |
| `EXECUTE_TYPESCRIPT_DESCRIPTION` (`tools/native/code_mode/prompts.py`) | before 2026-09-19, 7.5B model | The opening used to be "Write ONE script that does the whole task", the strongest imperative in the request, and the model obeyed it over the system prompt's "only when it saves round trips" every time; it now says what a program is for first. The `main()` sentence: the model wrapped its steps in `async function main()` and ended with `main();`, the body returned at once, the shim exited, and the reply in flight met a dead pipe, twice in two runs. |

"Call it directly" for one call and "a program" for many is Anthropic's own guidance, and what a 7.5B model could do where writing a correct program was beyond it. |
